# ХимЛаб 3D (`sim-chemistry`)

Интерактивная трёхмерная виртуальная лаборатория по химии на **Three.js (WebGL 2)** и чистых ES-модулях без внешних CDN-зависимостей.

## Возможности

- **3D-сцена и 3 специализированных лабораторных стола (`src/lab3d.js`)**:
  - **Перемещение с одного стола на другой**: плавный дуговой перенос сосуда с содержимым между тремя рабочими столами (`Стол 1: Горелка и газы`, `Стол 2: Термомешалка и аналитика`, `Стол 3: Муфельная печь и электролиз`) по клику на стол, кнопкам навигации и горячим клавишам `[` / `]`.
  - **6 видов лабораторной посуды**: коническая колба Эрленмейера (100 мл), круглодонная колба (150 мл), пробирка в штативе (25 мл), химический стакан (200 мл), глазурованная фарфоровая выпарительная чашка (80 мл) и огнеупорный фарфоровый тигель (40 мл, до `1000 °C`).
  - **Расширенный парк интерактивных 3D-приборов**: муфельная печь `ПМ-1000` (`600 °C` / `950 °C` с раскалённой шамотной камерой, спиралями ТЭНов, распахивающейся дверцей и ПИД-контроллером), магнитная мешалка с подогревом (`60 / 125 / 260 °C`, `600 об/мин`, две ручки и ЖК-табло), спиртовка с GLSL-пламенем, кристаллизатор с ледяной баней (`0…+2 °C`), титровальная бюретка на 25 мл, электролизёр постоянного тока `DC 12 В`, стеклянная воронка с фильтром, электронные весы, газометр, промывалка, лучина, нихромовая петля и щипцы.
  - PBR-стекло с эффектом Френеля, живой мениск жидкости, `InstancedMesh`-пузырьки газа, микропузырьки на катоде и аноде, покрытие катода медью `Cu⁰` / серебром `Ag⁰` и интеллектуальный спящий режим `3D Эко-сон`.
- **Физико-химический движок (`src/chemistry.js`, `src/reagents.js`)**:
  - **91 реактив** с индивидуальными векторными лабораторными иконками (`src/icons.js`), включая негашёную известь `CaO` (высокотемпературный обжиг `CaCO₃ → CaO + CO₂↑` при `T ≥ 780 °C` с потерей 44% массы и экзотермическое гашение извести `CaO + H₂O → Ca(OH)₂`).
  - Расчёт `pH` (с учётом гидролиза солей и ацетатного буфера), необратимого совместного гидролиза (`Al³⁺/Fe³⁺/Cr³⁺ + CO₃²⁻/SO₃²⁻/S²⁻`), выпадения, перекристаллизации (`PbI₂` «золотой дождь») и растворения осадков, амфотерности (`Al(OH)₃`, `Zn(OH)₂`, `Cr(OH)₃`), комплексообразования (`[Cu(NH₃)₄]²⁺`, `[Fe(SCN)]²⁺`, «берлинская лазурь», «турнбулева синь», `[Ag(S₂O₃)₂]³⁻`, фенолят железа(III), реактив Толленса, глицерат меди, клатрат иод-крахмал, биуретовая и ксантопротеиновая реакции).
  - Расширенные ОВР и органические синтезы: `KMnO₄` в трёх средах (кислая → `Mn²⁺`, нейтральная → `MnO₂↓`, щелочная → зелёный `MnO₄²⁻` «химический хамелеон»), хромат-дихроматное равновесие, гидролиз карбида кальция (`CaC₂ → C₂H₂↑`), тиосульфат с кислотой и галогенами, цементация меди и серебра, гальваническая пара `Zn–Cu`, этерификация (синтез этилацетата), окисление этанола на `CuO`, реакции фенола с `FeCl₃` и бромной водой `Br₂`.
  - Тепловой баланс с учётом теплоёмкости стекла и раствора, правило Вант-Гоффа, самоподдерживающийся «химический вулкан» `(NH₄)₂Cr₂O₇`, разложение сухого `KMnO₄`, малахита и возгонка `NH₄Cl`.
- **Лупа «Микромир» (`src/micro.js`)**: визуализация диполей воды, кристаллических решёток, гидратированных ионов и ионных уравнений в реальном времени.
- **30 практикумов (8–11 класс, ОГЭ/ЕГЭ) + свободная песочница (`src/tasks.js`)**: включая обжиг известняка в муфельной печи и гашение извести, синтез на магнитной мешалке с подогревом, электролиз `KI` и `CuSO₄`, испытание электропроводности неэлектролитов, капельное кислотно-основное титрование из бюретки и разделение смесей фильтрованием и выпариванием; конструктор уравнений реакций, заготовки опытов в 1 клик, честный стек `Undo / Redo` по снимкам состояния (`Ctrl+Z` / `Ctrl+Y`).
- **Процедурный звук (`src/audio.js`)**: синтез всех звуков на Web Audio API без внешних аудиофайлов.
- **Лабораторный отчёт (`src/report.js`)**: формирование и скачивание протокола `.html` / печать в PDF со встроенным снимком 3D-сцены, а также экспорт/импорт файлов опытов `.chemlab.json`.

## Быстрый старт

Проект не требует сборки и внешних зависимостей — достаточно Node.js 18+:

```bash
npm start
```

После запуска откройте в браузере `http://localhost:8081` (также можно развернуть как статический сайт на GitHub Pages — точка входа `index.html`).
