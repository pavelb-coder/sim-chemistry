# ХимЛаб 3D (`sim-chemistry`)

Интерактивная трёхмерная виртуальная лаборатория по химии на **Three.js (WebGL 2)** и чистых ES-модулях без внешних CDN-зависимостей.

## Возможности

- **3D-сцена (`src/lab3d.js`)**: коническая колба (100 мл), пробирка в штативе (25 мл) и химический стакан (200 мл), PBR-стекло с эффектом Френеля, живой мениск жидкости, наливание из склянки со струёй, `InstancedMesh`-пузырьки газа и кипения, хлопья осадков, 3D-спиртовка, газоотводная трубка с пробиркой-газометром и интеллектуальный спящий режим `3D Эко-сон`.
- **Физико-химический движок (`src/chemistry.js`, `src/reagents.js`)**:
  - **90 реактивов** с индивидуальными векторными лабораторными иконками (`src/icons.js`): металлы, разбавленные и концентрированные кислоты, щёлочи, соли, индикаторы, оксиды, неметаллы, газы, кристаллогидраты и органические вещества.
  - Расчёт `pH` (с учётом гидролиза солей и ацетатного буфера), необратимого совместного гидролиза (`Al³⁺/Fe³⁺/Cr³⁺ + CO₃²⁻/SO₃²⁻/S²⁻`), выпадения, перекристаллизации (`PbI₂` «золотой дождь») и растворения осадков, амфотерности (`Al(OH)₃`, `Zn(OH)₂`, `Cr(OH)₃`), комплексообразования (`[Cu(NH₃)₄]²⁺`, `[Fe(SCN)]²⁺`, «берлинская лазурь», «турнбулева синь», `[Ag(S₂O₃)₂]³⁻`, фенолят железа(III), реактив Толленса, глицерат меди, клатрат иод-крахмал, биуретовая и ксантопротеиновая реакции).
  - Расширенные ОВР и органические синтезы: `KMnO₄` в трёх средах (кислая → `Mn²⁺`, нейтральная → `MnO₂↓`, щелочная → зелёный `MnO₄²⁻` «химический хамелеон»), хромат-дихроматное равновесие, гидролиз карбида кальция (`CaC₂ → C₂H₂↑`), тиосульфат с кислотой и галогенами, цементация меди и серебра, гальваническая пара `Zn–Cu`, этерификация (синтез этилацетата), окисление этанола на `CuO`, реакции фенола с `FeCl₃` и бромной водой `Br₂`.
  - Тепловой баланс с учётом теплоёмкости стекла и раствора, правило Вант-Гоффа, самоподдерживающийся «химический вулкан» `(NH₄)₂Cr₂O₇`, разложение сухого `KMnO₄`, малахита и возгонка `NH₄Cl`.
- **Лупа «Микромир» (`src/micro.js`)**: визуализация диполей воды, кристаллических решёток, гидратированных ионов и ионных уравнений в реальном времени.
- **24 практикума (8–11 класс, ОГЭ/ЕГЭ) + свободная песочница (`src/tasks.js`)**: конструктор уравнений реакций, заготовки опытов в 1 клик, честный стек `Undo / Redo` по снимкам состояния (`Ctrl+Z` / `Ctrl+Y`).
- **Процедурный звук (`src/audio.js`)**: синтез всех звуков на Web Audio API без внешних аудиофайлов.
- **Лабораторный отчёт (`src/report.js`)**: формирование и скачивание протокола `.html` / печать в PDF со встроенным снимком 3D-сцены, а также экспорт/импорт файлов опытов `.chemlab.json`.

## Быстрый старт

Проект не требует сборки и внешних зависимостей — достаточно Node.js 18+:

```bash
npm start
```

После запуска откройте в браузере `http://localhost:8080` (также можно развернуть как статический сайт на GitHub Pages — точка входа `index.html`).
