# ХимЛаб 3D (`sim-chemistry`)

Интерактивная трёхмерная виртуальная лаборатория по химии на **Three.js (WebGL 2)** и чистых ES-модулях без внешних CDN-зависимостей.

## Возможности

- **3D-сцена, 3 специализированных стола и 3 параллельных сосуда (`src/lab3d.js`)**:
  - **Многососудный практикум и смешивание колб/пробирок (`① / ② / ③`)**: одновременная работа с тремя лабораторными сосудами (активный сосуд на установке + два вспомогательных на 3D-стойке с отображением реального уровня, цвета и свечения растворов), полное переливание (`🫗 Влить ② → ①`) и деление аликвоты пополам (`½ в ②`) с 3D-анимацией наклона сосуда и учётом теплоты нейтрализации / разбавления.
  - **Перемещение с одного стола на другой**: плавный дуговой перенос сосуда с содержимым между тремя рабочими столами (`Стол 1: Горелка и газы`, `Стол 2: Термомешалка и аналитика`, `Стол 3: Муфельная печь и электролиз`) по клику на стол, кнопкам навигации и горячим клавишам `[` / `]`.
  - **6 видов лабораторной посуды**: коническая колба Эрленмейера (100 мл), круглодонная колба (150 мл), пробирка в штативе (25 мл), химический стакан (200 мл), глазурованная фарфоровая выпарительная чашка (80 мл) и огнеупорный фарфоровый тигель (40 мл, до `1000 °C`).
  - **Расширенный парк интерактивных 3D-приборов**: УФ-лампа Вуда (`365 нм`, режим затемнённой фотолюминесцентной камеры, клавиша `U`), переносной электролизёр постоянного тока `DC 12 В` (устанавливается к непустому сосуду на любом выбранном столе), муфельная печь `ПМ-1000` (`600 °C` / `950 °C`), магнитная мешалка с подогревом (`60 / 125 / 260 °C`, `600 об/мин`), спиртовка с GLSL-пламенем, ледяная баня (`0…+2 °C`), титровальная бюретка на 25 мл, стеклянная воронка с фильтром, электронные весы, газометр, промывалка, лучина, нихромовая петля и щипцы.
  - PBR-стекло с эффектом Френеля, живой мениск жидкости, `InstancedMesh`-пузырьки газа, микропузырьки на катоде и аноде, покрытие катода медью `Cu⁰` / серебром `Ag⁰` и интеллектуальный спящий режим `3D Эко-сон`.
- **Физико-химический движок, квантовые точки и люминофоры (`src/chemistry.js`, `src/reagents.js`)**:
  - **97 реактивов** с индивидуальными векторными лабораторными иконками (`src/icons.js`), включая прекурсоры нанохимии и люминофоров: `CdCl₂`, `Na₂SeSO₃`, тиоловый стабилизатор `HSCH₂COOH (MPA)`, люминол `C₈H₇N₃O₂`, флуоресцеин `C₂₀H₁₂O₅` и борную кислоту `H₃BO₃`.
  - **Синтез квантовых точек и кристаллофосфоров**: коллоидные КТ `CdSe` с непрерывным квантово-размерным сдвигом фотолюминесценции при созревании Оствальда (`d = 2,0 → 5,6 нм`, `λ = 494 → 648 нм`: бирюзовый → зелёный → жёлтый → оранжевый → рубиново-красный; без стабилизатора `MPA` выпадает нелюминесцентный объёмный `CdSe↓`), КТ `CdS` (`472–500 нм`), углеродные `C-Dots` (`490 нм`), твердофазный муфельный кристаллофосфор `ZnS:Cu` (`525 нм` с длительным фосфоресцентным послесвечением), борный органолюминофор `B₂O₃·Люм` (`535 нм`) и двухколбовая хемилюминесценция люминола (`425 нм` без УФ-лампы).
  - Расчёт `pH` (с учётом гидролиза солей и ацетатного буфера), необратимого совместного гидролиза (`Al³⁺/Fe³⁺/Cr³⁺ + CO₃²⁻/SO₃²⁻/S²⁻`), выпадения, перекристаллизации (`PbI₂` «золотой дождь») и растворения осадков, амфотерности (`Al(OH)₃`, `Zn(OH)₃`, `Cr(OH)₃`), комплексообразования (`[Cu(NH₃)₄]²⁺`, `[Fe(SCN)]²⁺`, «берлинская лазурь», «турнбулева синь», `[Ag(S₂O₃)₂]³⁻`, фенолят железа(III), реактив Толленса, глицерат меди, клатрат иод-крахмал, биуретовая и ксантопротеиновая реакции).
  - Расширенные ОВР и органические синтезы: `KMnO₄` в трёх средах (кислая → `Mn²⁺`, нейтральная → `MnO₂↓`, щелочная → зелёный `MnO₄²⁻` «химический хамелеон»), хромат-дихроматное равновесие, гидролиз карбида кальция (`CaC₂ → C₂H₂↑`), обжиг известняка `CaCO₃ → CaO + CO₂↑` и гашение извести, тиосульфат с кислотой и галогенами, цементация меди и серебра, гальваническая пара `Zn–Cu`, этерификация, окисление этанола на `CuO`, реакции фенола.
  - Тепловой баланс с учётом теплоёмкости стекла и раствора, правило Вант-Гоффа, самоподдерживающийся «химический вулкан» `(NH₄)₂Cr₂O₇`, разложение сухого `KMnO₄`, малахита и возгонка `NH₄Cl`.
- **Лупа «Микромир» (`src/micro.js`)**: визуализация диполей воды, нанокристаллов квантовых точек с тиоловой оболочкой, испускаемых фотонов `hν`, кристаллических решёток, гидратированных ионов и уравнений реакций в реальном времени.
- **33 практикума (8–11 класс, ОГЭ/ЕГЭ и нанохимия) + свободная песочница (`src/tasks.js`)**: включая коллоидный синтез КТ `CdSe` с размерным сдвигом, муфельный синтез кристаллофосфора `ZnS:Cu` с послесвечением, двухколбовую хемилюминесценцию люминола, обжиг известняка в муфельной печи, синтез на термомешалке, электролиз `KI` и `CuSO₄`, титрование и разделение смесей; честный стек `Undo / Redo` по снимкам всех 3 сосудов (`Ctrl+Z` / `Ctrl+Y`).
- **Процедурный звук (`src/audio.js`)**: синтез всех звуков на Web Audio API без внешних аудиофайлов.
- **Лабораторный отчёт (`src/report.js`)**: формирование и скачивание протокола `.html` / печать в PDF со встроенным снимком 3D-сцены, а также экспорт/импорт файлов опытов `.chemlab.json`.

## Быстрый старт

Проект не требует сборки и внешних зависимостей — достаточно Node.js 18+:

```bash
npm start
```

После запуска откройте в браузере `http://localhost:8081` (также можно развернуть как статический сайт на GitHub Pages — точка входа `index.html`).
