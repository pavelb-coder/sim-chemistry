# Moodle plugin package

This folder contains the installable Moodle activity module source at `mod/chemlab3d/` and the ZIP build script.

Build the plugin ZIP from the repository root:

```bash
./moodle/build-plugin.sh
```

The installable archive is written to `moodle/mod_chemlab3d.zip`. Its archive root is the Moodle-required `chemlab3d/` plugin directory.

See [`mod/chemlab3d/README.md`](mod/chemlab3d/README.md) for requirements, Moodle installation steps, course setup, privacy notes, and limitations.
